# Hi, I'm James Wanjiku

I'm an AI/ML engineer and team lead, based in Nairobi. I build machine learning systems and get them into production: computer vision on drones, LLM pipelines and voice agents.

## Things I've built in the open

- **[Taura 2.0](https://github.com/Garnet-Owl/taura-2.0)** is Kikuyu to English machine translation. Free, open source, runs on a CPU.
- **[Nemo Voice Typing](https://github.com/Garnet-Owl/nemo-voice-typing)** is offline voice typing for Windows. Press a shortcut, talk, and it types.

## Research

- **[Token Compression](https://github.com/Garnet-Owl/token-compression)** is an experiment, not a product. I tried compressing prompts the way ZIP does and measured whether it really saves LLM tokens. It does on logs and JSON, and it loses on normal text. The repo has the numbers and the scripts.
